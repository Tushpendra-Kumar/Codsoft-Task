## 📌 Overview

A collection of three practical web development milestone projects completed during the **CodSoft Web Development Internship** program.

---

## ✨ Key Features

- **Task 1 — Landing Page:** High-converting product/service landing page featuring hero call-to-actions, feature spotlights, and modern layouts.
- **Task 2 — Developer Portfolio:** Interactive personal showcase highlighting development capabilities, skillsets, and social handles.
- **Task 3 — Web Calculator:** Fully functional mathematical calculator supporting standard arithmetic, decimal accuracy, and key feedback.

---

## 💻 Tech Stack & Architecture

- **Frontend Technologies:** HTML5, CSS3 (Flexbox/Grid/Animations), JavaScript ES6
